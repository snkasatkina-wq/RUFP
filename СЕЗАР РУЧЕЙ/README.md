## Рабочие продукты

- [Исследование: восстановление разрушенного коллектора (Москва)](issledovanie-vosstanovlenie-kollektora.md)

Проект заведён. Выполнено первичное исследование: балансодержатели, порядок обращения, перечни документов. Паспорт будет дополняться по мере поступления информации о договоре, этапах и рабочих продуктах.
